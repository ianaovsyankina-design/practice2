# Задание 2.4 — Абстрактный класс vs Интерфейс

## Теоретическое напоминание

| Критерий | Абстрактный класс | Интерфейс |
|----------|-------------------|-----------|
| Отношение | «является» (is-a) | «умеет» (can-do) |
| Наследование | Одиночное (`extends`) | Множественное (`implements`) |
| Поля (состояние) | Могут быть любые | Только `static final` |
| Конструктор | Есть | Нет |
| Методы с реализацией | Да | `default`/`static` (с Java 8) |

**Правило выбора:**
- Если есть общие **поля** (состояние) и отношение «является» → **абстрактный класс**.
- Если нужна **множественная реализация** или отношение «умеет» → **интерфейс**.

## Ваша таблица

| Ситуация | Ваш выбор | Обоснование |
|----------|-----------|-------------|
| Все животные имеют имя и возраст, но звучат по-разному |Абстрактный класс | Есть общее состояние (имя, возраст) — поля, которые хранятся. Отношение «является» (is-a). Животные имеют общую структуру данных.|
| Некоторые объекты (документ, изображение, настройки) можно сериализовать |Интерфейс |Отношение «умеет» (can-do). Нет общего состояния, нужна множественная реализация (объект может одновременно сериализоваться и быть, например, документом). |
| Все транспортные средства имеют скорость и топливо, но двигаются по-разному | Абстрактный класс|Есть общее состояние (скорость, топливо) — поля. Отношение «является». Разные виды транспорта (машина, самолёт) имеют общие характеристики. |
| Робот, посудомоечная машина и телефон — все умеют подключаться к Wi-Fi |Интерфейс | Отношение «умеет» (can-do). Объекты из совершенно разных категорий имеют одну общую способность. Нет общего состояния и отношения «является».|
| Круг, квадрат и треугольник — все фигуры с площадью и периметром, у всех есть цвет | Абстрактный класс|Есть общее состояние (цвет) — поле. Отношение «является» (is-a). Все фигуры имеют общие характеристики и методы (площадь, периметр). |
| Класс должен одновременно уметь летать, плавать и ездить |Интерфейс | Нужна множественная реализация. В Java можно реализовать несколько интерфейсов, но наследовать только один класс. Интерфейсы лучше подходят для «способностей».|
