## Вопрос 1

Что выведет этот код? Объясните порядок выполнения блоков.

```java
class Demo {
    static { System.out.print("A "); }
    { System.out.print("B "); }
    Demo() { System.out.print("C "); }
    public static void main(String[] args) {
        System.out.print("D ");
        new Demo();
        System.out.print("E ");
        new Demo();
    }
}
```

**Предсказанный вывод:**

```
A D B C E B C
```

**Объяснение:**

A — статический блок выполняется один раз при загрузке класса

D — первая инструкция в методе main

B C — при создании первого объекта: сначала блок инициализации, затем конструктор

E — вторая инструкция в main

B C — при создании второго объекта: снова блок инициализации и конструктор

## Вопрос 4

Что выведет этот код? Объясните, что такое String Pool и как работает `intern()`.

```java
String a = "Hello";
String b = new String("Hello");
String c = b.intern();
System.out.println(a == b);
System.out.println(a == c);
System.out.println(b == c);
```

**Предсказанный вывод:**

```
false
true
false
```

**Объяснение:**
String Pool — специальная область памяти JVM, где хранятся уникальные строковые литералы.

a — литерал, хранится в String Pool
b — создан через new, хранится в куче (heap)
c = b.intern() — возвращает ссылку из String Pool (тот же объект, что и a)
a == b → разные объекты (пул vs куча) → false
a == c → оба из пула → true
b == c → куча vs пул → false

## Вопрос 5

Почему этот код не компилируется? Как исправить?

```java
interface A { default void hello() { System.out.println("A"); } }
interface B { default void hello() { System.out.println("B"); } }
class C implements A, B { }
```

**Ваш ответ:**
Класс C наследует два одинаковых метода hello() из интерфейсов A и B — конфликт. Компилятор не может выбрать, какой метод использовать.

## Вопрос 6

В чём разница между `StringBuilder` и `StringBuffer`? Приведите конкретный сценарий, когда нужен именно `StringBuffer`.

**Ваш ответ:**
StringBuffer — все методы синхронизированы (synchronized), поэтому он потокобезопасен. Это означает, что несколько потоков могут одновременно работать с одним объектом StringBuffer без риска повреждения данных. Однако синхронизация добавляет накладные расходы, поэтому StringBuffer работает медленнее.
StringBuilder — не синхронизирован, поэтому он не является потокобезопасным. Но за счёт отсутствия синхронизации он работает значительно быстрее. StringBuilder появился в Java 5 как более быстрая альтернатива StringBuffer для однопоточных сценариев.

Сценарий для StringBuffer: Многопоточное приложение, где несколько потоков одновременно записывают данные в общий буфер (например, логгер с записью в строку из разных потоков).

## Вопрос 7

Что выведет этот код? Объясните, что происходит с переменной `x` в лямбде.

```java
int x = 10;
Runnable r = () -> System.out.println(x);
// x = 20;  // что будет, если раскомментировать?
r.run();
```

**Предсказанный вывод:**

```
10
```

**Объяснение:**

Лямбда захватывает переменную x, которая должна быть effectively final (фактически неизменяемой). Если раскомментировать x = 20, код не скомпилируется, так как x перестанет быть effectively final.

## Вопрос 8

Напишите пример лямбда-выражения, которое нельзя заменить на ссылку на метод. Объясните почему.

**Ваш пример и объяснение:**

Predicate<Integer> isEven = n -> n % 2 == 0;

Почему нельзя заменить: Лямбда выполняет несколько операций (вычисление остатка от деления и сравнение с нулём), а не просто вызывает один метод. Ссылка на метод работает только когда лямбда напрямую вызывает один метод с переданными параметрами.

## Вопрос 9

Чем `EnumMap` быстрее `HashMap` для ключей-enum? Опишите внутреннюю реализацию в одном предложении.

**Ваш ответ:**
EnumMap использует обычный массив, индексированный по ordinal() ключа, что даёт O(1) доступ без вычисления хеш-кода и обработки коллизий.

## Вопрос 10

Дан `record Point(int x, int y) {}`. Что сгенерирует компилятор автоматически? Можно ли добавить в record изменяемое поле? Можно ли наследоваться от record?

**Ваш ответ:**
Компилятор автоматически сгенерирует:

Конструктор Point(int x, int y)
Геттеры x() и y()
equals(), hashCode(), toString()

Можно ли добавить изменяемое поле?
Нет, все поля record финальные (final).

Можно ли наследоваться от record? Нет, record финальный.
